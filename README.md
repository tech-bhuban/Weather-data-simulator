
# 🌤️ Weather Data Simulator

A comprehensive weather monitoring and analysis system that simulates, tracks, and analyzes weather data with predictive capabilities.

## 📡 Features
- **Weather Data Simulation**: Generate realistic weather data
- **Real-time Monitoring**: Track temperature, humidity, pressure, wind
- **Statistical Analysis**: Calculate averages, extremes, and trends
- **Weather Prediction**: Simple predictive modeling
- **Heat Index Calculation**: Real-feel temperature with warnings
- **Visual Trends**: Temperature trends with indicators
- **Extreme Weather Detection**: Identify record-breaking conditions

## 🚀 Quick Start
```bash
# Compile
g++ -o weather_simulator weather_simulator.cpp

# Run
./weather_simulator
